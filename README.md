# MaanLabs / .github

This repository holds organization-wide community health files and shared
GitHub configuration for MaanLabs. Files here apply as defaults across the
repositories in the organization unless a repository defines its own.

## Contents

- `CONTRIBUTING.md` — contribution guidelines
- `SECURITY.md` — security policy and how to report a vulnerability
- `PULL_REQUEST_TEMPLATE.md` — default pull request template
- `ISSUE_TEMPLATE/` — default issue templates
