# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in a MaanLabs
repository, please report it responsibly and privately — **do not open a
public GitHub issue for a security vulnerability.**

Where available for the affected repository, please use GitHub's
**Private Vulnerability Reporting** (repository → Security tab → Report a
vulnerability). This keeps the report private between you and MaanLabs
until it is resolved.

Please include:

- The affected repository or service.
- A description of the vulnerability and its potential impact.
- Steps to reproduce, including version/commit where relevant.
- Any proof-of-concept code or other evidence, if available.

## Scope

This policy applies to repositories owned by the MaanLabs GitHub
organization. Third-party dependencies should be reported to their
respective maintainers.
